# 🧩 Java vs JRE vs JVM (Summary)

-   **Java** → The **programming language and platform** used to write
    programs.\
-   **JVM (Java Virtual Machine)** → Executes Java **bytecode**,
    converts it to **machine code**, and handles memory and runtime
    tasks.\
-   **JRE (Java Runtime Environment)** → Provides everything needed to
    **run** Java programs --- includes the **JVM** and core
    **libraries**.\
-   **JDK (Java Development Kit)** → Used to **develop** Java programs
    --- includes the **JRE**, **JVM**, and developer tools (like
    `javac`).

------------------------------------------------------------------------

## 📊 Relationship

**Java Code (.java)** → compiled by **JDK** → produces **Bytecode
(.class)** → executed by **JVM** (inside **JRE**).
